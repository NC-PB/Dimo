# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/NC-PB/dimo/security/advisories/new).
Do not open a public issue.

You can expect a first answer within 14 days. Dimo is maintained by a single person, so fixes are
prioritized by severity.

## Scope

Of particular interest: crafted drawings or project files that cause code execution, file system
access outside the user's choice, or network access; template rendering escaping its sandbox.

## Supported versions

Only the latest release receives security fixes until 1.0.
