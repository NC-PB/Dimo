# Keyboard shortcuts

Press **?** in the app to see this list. On macOS **⌘** is the Command key and **⌥** is Option.
On Windows and Linux the same keys are Ctrl and Alt. Where an action has more than one key, any of
them works.

Single keys such as **B**, **V**, **R** or **0** act on the drawing only while the drawing, not a
text field or the characteristic table, has the keyboard focus, and only while the Drawing view is
shown. Combinations with ⌘ (Ctrl) work everywhere.

The tables below are checked against the shortcut definitions of the app by a test, so they stay
complete.

## Mouse and trackpad

| Action | How |
|---|---|
| Zoom around the pointer | Mouse wheel or pinch |
| Move the drawing | Middle mouse button, or Space and drag |
| Select a balloon | Click it |
| Add a balloon to the selection or remove it | Shift+click or ⌘+click (Ctrl+click) |
| Select balloons in an area | Shift and drag on empty drawing |
| Place a balloon at a point | Place balloon tool, click |
| Read a dimension (box select) | Place balloon tool, drag a box; Enter accepts the card, Escape discards it |
| Open the value field of a balloon | Double click it |
| Move balloons | Drag them |
| Move the end of a leader line | Drag the square handle of a selected balloon |
| Change the table height | Drag the line above the table |
| Move table rows | Drag the handle ⠿ in the No column |
