# Settings

Open the **Settings** view from the toolbar (Cmd+, on macOS, Ctrl+, elsewhere). Changes apply
at once and are kept for the next start.

## Appearance

- **Theme**: same as the system, light or dark.
- **Language**: same as the system, English or German. The window reloads when the language
  changes; the open project stays open.

## Audit log

- **User name**: recorded with every change of a project. Leave it empty to use the user name
  of the operating system, which the field shows in grey.

## Balloon style of this project

Shown while a project is open. Shape, size, line width, outline color and leader line of all
balloons of the project that have no style of their own. A change is one step of undo, like
every other change of the project. To give single balloons their own style, select them in the
drawing and use **Style** (S).
