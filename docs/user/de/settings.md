# Einstellungen

Öffne die Ansicht **Einstellungen** in der Werkzeugleiste (Cmd+, auf macOS, Strg+, sonst).
Änderungen gelten sofort und bleiben für den nächsten Start erhalten.

## Darstellung

- **Farbschema**: wie das System, hell oder dunkel.
- **Sprache**: wie das System, Englisch oder Deutsch. Beim Wechsel der Sprache wird das Fenster
  neu geladen; das offene Projekt bleibt offen.

## Änderungsprotokoll

- **Benutzername**: wird bei jeder Änderung an einem Projekt festgehalten. Leer lassen, um den
  Benutzernamen des Betriebssystems zu verwenden, den das Feld grau anzeigt.

## Ballonstil dieses Projekts

Sichtbar, solange ein Projekt offen ist. Form, Größe, Linienbreite, Randfarbe und Bezugslinie
aller Ballons des Projekts ohne eigenen Stil. Eine Änderung ist ein Schritt beim Rückgängigmachen,
wie jede andere Änderung am Projekt. Einzelnen Ballons gibst du einen eigenen Stil, indem du sie
in der Zeichnung auswählst und **Stil** (S) verwendest.
