# Tastenkürzel

Drücke **?** in der App, um diese Liste zu sehen. Auf macOS ist **⌘** die Befehlstaste und **⌥**
die Wahltaste. Unter Windows und Linux sind es dieselben Tasten wie Ctrl (Strg) und Alt. Hat eine
Aktion mehrere Tasten, funktioniert jede davon.

Einzelne Tasten wie **B**, **V**, **R** oder **0** wirken nur dann auf die Zeichnung, wenn die
Zeichnung, nicht ein Textfeld oder die Merkmalstabelle, den Tastaturfokus hat, und nur solange die
Ansicht Zeichnung gezeigt wird. Kombinationen mit ⌘ (Ctrl) wirken überall.

Die Tabellen unten werden von einem Test gegen die Kürzeldefinitionen der App geprüft und bleiben
darum vollständig.

## Karte der Rahmenauswahl und getippte Werte

Diese Tasten wirken, solange die Vorschlagskarte einer Rahmenauswahl oder das Wertfeld eines
Ballons offen ist, und auch auf der Zeichnung in dem Moment zwischen dem Klick und dem Öffnen der
Karte oder des Felds.

| Aktion | Taste |
|---|---|
| Die Vorschläge der Karte übernehmen oder den Wert speichern | Enter |
| Die Karte verwerfen oder das Wertfeld schließen, ohne zu speichern | Esc |
| Den Wert oder den Anforderungstext tippen | Jedes Zeichen, auch gleich nach dem Klick oder dem Rahmen |
| Das Zeichnen eines Zonenrahmens oder einer Ansicht abbrechen | Esc |

| Aktion | So geht es |

| Um den Zeiger zoomen | Mausrad oder Spreizen und Zusammenziehen |
| Zeichnung verschieben | Mittlere Maustaste, oder Leertaste und ziehen |

| Ballon zur Auswahl hinzufügen oder entfernen | Shift+Klick oder ⌘+Klick (Ctrl+Klick) |
| Ballons in einer Fläche auswählen | Shift gedrückt halten und auf leerer Zeichnung ziehen |
| Ballon an einem Punkt setzen | Werkzeug Ballon setzen, klicken |
| Ein Maß lesen (Rahmenauswahl) | Werkzeug Ballon setzen, einen Rahmen ziehen; Enter übernimmt die Karte, Escape verwirft sie |
| Wertfeld eines Ballons öffnen | Doppelklick darauf |
| Ballons verschieben | Ziehen |
| Ende einer Bezugslinie verschieben | Quadratischen Griff eines ausgewählten Ballons ziehen |
| Höhe der Tabelle ändern | Linie über der Tabelle ziehen |
| Tabellenzeilen verschieben | Griff ⠿ in der Spalte Nr ziehen |
