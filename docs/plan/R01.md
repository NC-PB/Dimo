# Release 0.1 First public release

Goal from [09 Roadmap](../spec/09-roadmap.md): unsigned installers (D-08), a getting started guide
including first launch instructions, a demo drawing, all shipped tolerance tables verified (D-43).
Added by the owner on 2026-10-14: drawings from images (scans and phone photos) with rotate, trim
and resize, ballooned and measured by hand (R.19 to R.22). Automatic reading of images (OCR) stays
in a later milestone.

**Exit criterion:** usable by small shops without help. Measured: a person from a small shop who
has not seen Dimo downloads the release from GitHub on a Windows PC, installs it with only the
getting started guide, opens the demo drawing, and finishes the guided example (balloon, measure,
issue a report) without asking anyone. Then the same person photographs a printed drawing with a
phone, opens the photo in Dimo, straightens and trims it, and balloons three dimensions. Procedure in `docs/perf/R01-exit.md` (R.30).

Status of this plan: **written 2026-10-14, decisions answered and ADR 0008 accepted by the owner the same day. No code
until the owner says so.**

Requirements in scope: FR-DOC-02 (manual work only, moved from M5 by the owner), D-03, D-04, D-05, D-06, D-07, D-08, D-10, D-11, D-43, NFR-PORT-01,
NFR-PORT-02, NFR-PORT-03, NFR-REL-04, NFR-SEC-01, NFR-SEC-03, NFR-UX-02, NFR-UX-06, Q-01.

Out of scope: code signing and notarization (reconsidered before 1.0, D-08), Windows ARM64 (after
1.0, D-10), auto detection, OCR and everything else from M4 on.

## Decisions

Answered by the owner on 2026-10-14.

1. **Update check:** a "Check for update" button. If a newer release exists, Dimo shows a link to
   the GitHub release page; it never downloads or installs anything. No automatic check, no first
   run question. Changes D-05: [ADR 0008](../adr/0008-update-check-link-only.md) (accepted).
2. **Platforms:** all three as D-10 says: Windows (MSI and portable), macOS (universal DMG, ad-hoc
   signed), Linux (AppImage and deb, tested on Ubuntu 22.04).
3. **Demo drawing:** a new demo drawing drawn by the owner for this purpose (simple part, title
   block with ISO 2768-mK, about 15 to 20 dimensions incl. one fit, one angle, one thread, one
   reference dimension, two sheets), with a matching finished sample project. Owner to do.
4. **Sponsor link:** left out of 0.1 (no donation service set up yet).
5. **Download:** GitHub Releases only (D-04); cnc-master.xyz/dimo links to it.
6. **Version and name:** `0.1.0`, product name "Dimo", bundle identifier `io.github.nc-pb.dimo`.
7. **Image formats:** JPEG, PNG and TIFF (incl. multi-page TIFF, one sheet per page). HEIC is not
   supported, now or later; Dimo shows a clear message with the two fixes (iPhone setting "Most
   Compatible", or send the photo by mail or messenger, which usually converts it to JPEG).
8. **Perspective correction:** included: drag four handles onto the sheet corners, Dimo makes the
   sheet a rectangle (proposes the corners when the sheet edge is easy to find, else starts at the
   image corners).
9. **Resize means paper format:** the user picks the paper format the photo shows (A4, A3, A2,
   A1, A0, Letter, Tabloid, or custom width and height in mm), portrait or landscape; the trimmed
   image is mapped onto that sheet. Large photos are reduced to at most 300 dpi at that size. No
   free scaling by percent.
10. **Non-destructive editing:** the original image is stored unchanged (its SHA-256 is the drawing
   fingerprint); rotate, trim, corners and paper format are stored as settings and can be changed
   later. Placed balloons keep their place on the drawing (positions converted), or Dimo asks
   before a change that would move them off the sheet.
11. **Image clean-up:** included as an optional "Clean up" switch (grey scale, background made
   white, contrast raised) for display and the ballooned PDF; the original stays as it is.

### R.19 Images as drawings: open and store (agent)

- New project from an image file (JPEG, PNG, TIFF, multi-page TIFF; decision 7) next to PDF, in
  the start screen, File > New and the open dialog. EXIF orientation of photos honoured.
- Data model: a drawing source can be a PDF or an image with its edit settings (decision 10);
  schema version 4 with a migration from 3 (NFR-REL-03). Original stored unchanged in the project
  container, fingerprint SHA-256 as for PDFs. ADR for the new drawing source type.
- Rendering: the tile service serves image sheets as it serves PDF pages (rule 4: sheet space in
  PDF user units from the chosen paper size); memory limit per decision 9.
- Box select on an image finds no text and falls back to manual placement (as today for PDFs
  without text); typed values, tolerances, measuring and reports work as for PDFs.
- Dependency: an image decoding library with JPEG, PNG and TIFF support, MIT/Apache or similar,
  pinned, at least 14 days old (plan mode).

Acceptance:
- [ ] A JPEG photo, a PNG and a 3-page TIFF open as projects, offline
- [ ] Save, reopen and re-export give byte identical files (rule 11)
- [ ] Version 3 projects open and save as version 4 (migration test)

### R.20 Image editing: rotate, trim, resize, corners (agent)

- "Adjust image" on the Drawing tab (and offered right after opening an image, as the first step
  of the setup pane): rotate in 90 degree steps and fine rotation (straighten, about plus or minus
  10 degrees with a slider and a typed angle), trim with a rectangle, four-corner correction
  (decision 8), paper format and orientation (decision 9), optional clean-up (decision 11).
- Live preview, Reset, Apply as one undoable command; all values changeable later (decision 10).
- The image math runs in Rust (rule 2) and is deterministic (same input, same pixels).
- Balloons already placed: converted to the new sheet positions, or a question before a change
  that would move them off the sheet.

Acceptance:
- [ ] A skewed phone photo of a drawing becomes a straight sheet in under a minute (manual test)
- [ ] Undo restores the previous edit; balloons stay on their features (test)

### R.21 Ballooned PDF and reports from image drawings (agent)
