# Release 0.1 First public release

Goal from [09 Roadmap](../spec/09-roadmap.md): unsigned installers (D-08), a getting started guide
including first launch instructions, a demo drawing, all shipped tolerance tables verified (D-43).

**Exit criterion:** usable by small shops without help. Measured: a person from a small shop who
has not seen Dimo downloads the release from GitHub on a Windows PC, installs it with only the
getting started guide, opens the demo drawing, and finishes the guided example (balloon, measure,
issue a report) without asking anyone. Procedure in `docs/perf/R01-exit.md` (R.30).

Status of this plan: **draft, written 2026-10-14, no code until the owner says so.** Decisions
below are open until the owner answers them.

Requirements in scope: D-03, D-04, D-05, D-06, D-07, D-08, D-10, D-11, D-43, NFR-PORT-01,
NFR-PORT-02, NFR-PORT-03, NFR-REL-04, NFR-SEC-01, NFR-SEC-03, NFR-UX-02, NFR-UX-06, Q-01.

Out of scope: code signing and notarization (reconsidered before 1.0, D-08), Windows ARM64 (after
1.0, D-10), auto detection, OCR and everything else from M4 on.

## Decisions for the owner

Each has a recommendation. **Owner: decide.**

1. **Update check in 0.1 (D-05).** D-05 asks for the Tauri updater against GitHub Releases, off by
   default and offered once in a first run dialog. It needs an updater key pair and adds one
   opt-in network call. Recommendation: build it as D-05 says (first run dialog offers it, off by
   default, one check per start when on, never downloads without asking). Alternative: no updater
   in 0.1, the first run dialog only links to the release page; that changes D-05 and needs an
   ADR.
2. **Platforms in 0.1 (D-10).** Recommendation: all three as D-10 says. Windows (primary, MSI plus
   portable build), macOS (universal DMG, ad-hoc signed), Linux (AppImage and deb, tested on Ubuntu
   22.04). Alternative: Windows and macOS only, Linux as "community tested".
3. **Demo drawing.** Recommendation: a new demo drawing drawn by the owner for this purpose
   (simple part, title block with ISO 2768-mK, about 15 to 20 dimensions incl. one fit, one angle,
   one thread, one reference dimension, two sheets), with a matching finished sample project.
   Alternative: reuse `corpus/drawings/test_drawing_1.pdf` (already licensed Apache 2.0 in
   PROVENANCE.md).
4. **Sponsor link (D-07).** Optional sponsor link in About and on cnc-master.xyz/dimo.
   Recommendation: leave it out of 0.1, decide after 0.1.
5. **Where the download lives.** Recommendation: GitHub Releases is the only download (D-04);
   cnc-master.xyz/dimo links to it and shows the getting started guide.
6. **Version and name.** Recommendation: `0.1.0`, product name "Dimo", bundle identifier stays
   `io.github.nc-pb.dimo` (already set; changing it later breaks settings paths).
