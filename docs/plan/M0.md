# M0 Foundations

Goal from [09 Roadmap](../spec/09-roadmap.md): repository, workspace, CI with license checks,
Tauri shell, pdfium tiles over a custom protocol, viewport with pan and zoom.

**Exit criterion:** a 50 sheet A0 PDF opens and pans smoothly on reference hardware
(NFR-PERF-01: first sheet under 2 s, NFR-PERF-02: 60 fps with 500 balloons, NFR-PERF-03: under 1.5 GB).

Tasks are ordered. Each task ends with green `./scripts/check.sh` and a signed commit.

## T0.5 PDFium integration in dimo-pdf

Refs: ADR 0005, [06 Tech stack](../spec/06-tech-stack.md), D-10

- `scripts/pdfium.toml` with pinned prebuilt PDFium release, URLs and SHA-256 per platform and arch.
- `scripts/fetch-pdfium.sh` (and `.ps1` for Windows) downloads to `vendor/pdfium/`, verifies checksums.
- `dimo-pdf`: open document from bytes, compute SHA-256 (FR-DOC-07), sheet count and sizes in sheet
  units, render a region at a zoom level to an RGBA buffer. Errors as `thiserror` enum.
- PDFium is not thread safe: one dedicated render thread or a mutex guarded instance; document the choice.

Acceptance:
- [ ] Test on `corpus/drawings/test_drawing_1.pdf`: 1 sheet, 1584 x 1224 units, hash matches PROVENANCE.md
- [ ] Rendered tile snapshot (dimensions plus checksum of a downscaled image) is stable

## T0.7 Tile protocol and cache

Refs: [05 Architecture](../spec/05-architecture.md) viewport and IPC

- Custom URI scheme `dimo://tile/{doc}/{sheet}/{zoom}/{x}/{y}` registered in `src-tauri`.
- Tile size 512 px, zoom levels as powers of two. Rendering on a worker pool, in memory LRU cache with
  byte budget, disk cache in the user cache dir keyed by file hash (never in the project).
- Requests for tiles no longer visible can be cancelled.

Acceptance:
- [ ] Tiles load in the webview from the custom scheme on macOS (and Windows in CI build)
- [ ] Cache budget respected under a stress test
