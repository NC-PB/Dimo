# Standard license texts

Fallback texts for `scripts/third-party-licenses.mjs` (T3.23). The generator uses a file here only
when a component states a license but ships no file with its text. The file name is the SPDX
identifier, with spaces replaced by `_`.

Source: the SPDX License List, repository `spdx/license-list-data`, tag `v3.27.0`, folder `text/`.
The files are unchanged. To add one, download `text/<id>.txt` of the same tag.
