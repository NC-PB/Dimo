# Standard license texts

Standard texts for `scripts/third-party-licenses.mjs` (T3.23). The generator uses a file here when
a component states a license but ships no file with its text, and for the texts in
`/usr/share/common-licenses/` that the Debian copyright files of the Linux AppImage libraries
refer to (`COMMON_LICENSES` in the generator, `scripts/appimage/`). The file name is the SPDX
identifier, with spaces replaced by `_`.

Source: the SPDX License List, repository `spdx/license-list-data`, tag `v3.27.0`, folder `text/`.
The files are unchanged. To add one, download `text/<id>.txt` of the same tag.
